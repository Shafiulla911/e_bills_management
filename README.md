# E-Bills & Customer Khata Management System

Full-stack E-Bill, Invoice & Customer Udhar Khata Management application built with React, Node.js, Express, and SQLite.

## 🚀 Features

- 🧾 **Itemized Digital E-Bill Generation**: Fast billing with item lookup, auto total & balance calculation.
- 📱 **WhatsApp PDF & Photo Sharing**: One-click sharing of E-Bill receipts directly via WhatsApp.
- 💰 **Customer Udhar Khata**: Track partial payments, total pending dues, and payment settlement history.
- ✒️ **Attractive E-Signature & Shop Watermark**: Customizable cursive signatures, ink colors, and digital verification stamp.
- 📊 **Analytics Dashboard**: Real-time sales, pending dues tracking, and top customer ledgers.

## 🛠️ Getting Started

### 1. Server (Backend)
```bash
node server/server.js
```
Runs on `http://localhost:5000`

### 2. Frontend (React App)
```bash
npm start
```
Runs on `http://localhost:3000`
